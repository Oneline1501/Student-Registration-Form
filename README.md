Student Registration Form

A simple and responsive Student Registration Form created using HTML, Tailwind CSS, and JavaScript.

🚀 Project Overview

This project allows users to enter student details through a registration form. After submitting the form, the entered student information is dynamically displayed in a table using JavaScript.

The project is designed to practice:

- HTML form creation
- Tailwind CSS styling
- JavaScript DOM manipulation
- Form validation
- Dynamic table creation
- Event handling

🛠️ Technologies Used

- HTML5 – Structure of the webpage
- Tailwind CSS – Styling and responsive design
- JavaScript – Form handling and dynamic table generation

✨ Features

- Student registration form
- Student Name input
- Email input
- Phone Number input
- Date of Birth input
- Gender selection
- Course selection
- Form validation
- Add student details dynamically
- Display registered students in a table
- Responsive design using Tailwind CSS
- No page refresh when submitting the form

💻 How It Works

1. The user enters student details in the registration form.
2. JavaScript captures the form values.
3. The form submission event is handled using JavaScript.
4. The entered details are added dynamically to the table.
5. Tailwind CSS is used to style the form and table.
6. The page does not need to reload when a student is added.

▶️ How to Run

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project

Open the project folder in Visual Studio Code.

3. Run the project

Open "index.html" in your browser.

If you are using the Tailwind CLI, make sure the Tailwind build command is running:

npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
